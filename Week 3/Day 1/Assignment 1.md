# Student Attendance Management System – Data Collection Report


## 1. Objective

The objective of this project is to collect, organize, and analyze student attendance records for one week. The collected data helps monitor student attendance, identify absent students, calculate attendance percentage, and support academic decision-making.

---

## 2. Data Requirement

The following data fields were identified as necessary for the attendance management system.

| Field Name | Description |
|---|---|
| Student ID | Unique identification number assigned to each student |
| Student Name | Name of the student |
| Department | Academic department of the student |
| Date | Date on which attendance was recorded |
| Attendance Status | Indicates whether the student was Present or Absent |

---

## 3. Data Collection Method

### Data Source

For this assignment, a realistic sample dataset was created for academic demonstration purposes because real student attendance records were not available.

### Collection Method

The data was collected using **manual data entry**.

### Type of Data

- Structured Data
- Primary Data (created specifically for this assignment)

### Number of Records

20 attendance records

---

## 4. Data Collection Process

The data collection process followed the standard data gathering lifecycle.

**Step 1: Define the Objective**
Determine the purpose of collecting student attendance data.

**Step 2: Identify Required Fields**
Select the information required for attendance analysis, such as Student ID, Student Name, Department, Date, and Attendance Status.

**Step 3: Collect Data**
Create attendance records through manual data entry.

**Step 4: Validate Data**
Verify that:

- Student IDs are unique.
- Student names are entered correctly.
- Dates follow a consistent format.
- Attendance values are only "Present" or "Absent".

**Step 5: Store Data**
Store the validated data in an Excel spreadsheet.

**Step 6: Analyze Data**
Calculate attendance statistics such as total records, number of present students, number of absent students, and attendance percentage.

**Step 7: Represent Data**
Display the results using tables and charts for easier understanding.

---

## 7. Data Validation

The following validation checks were performed before storing the data:

- Student ID should not be blank.
- Student ID should be unique.
- Student Name should contain valid text.
- Department should be correctly entered.
- Date should follow the DD-MMM-YYYY format.
- Attendance should only contain "Present" or "Absent".
